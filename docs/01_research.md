## 2. ベンチマーク詳細：クライアントパートナーズ

### 基本情報
- 本店：東京都新宿区西新宿（電話受付10〜23時、土日祝も営業）
- 24時間対応・秘密厳守をうたっている
- 全国に店舗あり（秋葉原店、大阪梅田店など）

### サービス範囲（かなり広い）
- **生活**：家事代行、介護サポート、ゴミ部屋の掃除、限定品の購入、場所取り、安否確認、ヘアセットの補助
- **ビジネス**：営業代行、経理代行、事務やイベントスタッフ、経営者サポート
- **人間関係・心のケア**：相談相手、レンタル家族・友人・母、浮気・モラハラ・DVの相談、退職の手続き
- **その他**：通訳・翻訳、観光案内、ホームページ制作、スマホ・SNS・パソコンのサポート、付き添い、チラシ配り、推し活代行
- 掃除系（トイレ・お風呂・エアコン・換気扇など）は、くらしのマーケットにも出店している

### ご利用の流れ（4ステップ）
1. メールか電話で相談
2. 内容を聞いて無料で見積もり
3. 見積もりに納得したら予約確定
4. 当日作業、支払い

### 支払い・キャンセル
- 支払い：前日までの銀行振込／当日現金／クレジットカード／PayPay（原則前払い）
- キャンセル料：2日前30％、前日50％、当日100％（3日前までは無料）

### 良い点（取り入れたい）
- 「女性スタッフ」という**誰に頼めるかがはっきりした安心感**
- 流れが4ステップで単純
- 支払い方法・キャンセル規定をはっきり書いている
- 本当に何でも頼める幅の広さ

### 改善できそうな点（推測）
- サービスが多すぎて「自分の困りごとがどれに当たるか」を探しにくい
- 料金が「〜円から」なので、**最終的にいくらになるか**がわからない
- 主な連絡手段が電話とメール。LINEで頼めると便利な層も多い
- 前払いが基本なので、初めて使う人は不安かもしれない

## 3. 業界の共通課題（＝差別化ポイント）

### ① 料金がわかりにくい
- ほとんどの競合が「作業費＋出張費＋車両費＋追加30分ごと」という**足し算方式**。
- 「〜円から」表記が多く、最終金額がわからない。
- 作業後に高額な追加料金を請求されるトラブルは、業界全体の不安材料（お助けマスターのコラムでも取り上げられている）。

### ② 高齢者の契約トラブル
- 国民生活センターは、高齢者向けサポートサービスの契約トラブルに注意を呼びかけ。「サービス内容・支払総額・解約条件を確認する」「よくわからなければその場で決めずに周りの人に相談する」ことを勧めている。
- → **家族と一緒に見られる・共有できる仕組み**がそのまま信頼につながる。

### ③ サービスを探しにくい
- メニュー数が多く、カテゴリの名前が業者目線（例：「代行」「代理」）。
- 利用者は「電球が替えられない」「棚が重くて動かせない」のように**困りごとの言葉**で考えている。

### ④ 依頼方法が電話かフォームの二択
- 電話は安心だが、受付時間が限られている。
- フォームは入力項目が多いと途中でやめてしまう。

## 5. UI/UXの設計原則（調査から導いたもの）

| 原則 | 具体的なルール |
|---|---|
| 大きく | 本文は18px以上、ボタンは高さ56px以上で画面いっぱいの幅。タップ領域は最低44×44px |
| 少なく | 1画面に伝えることは1つ。選択肢は最大6個まで |
| 言葉は易しく | カタカナ語・専門用語は使わない（CTA→「電話で相談」、見積もり→「料金を確認」など） |
| 色だけに頼らない | 青色は高齢者が見分けにくいことがある。ボタンには文字とアイコンを両方つけ、コントラスト比は4.5:1以上 |
| 料金は合計で見せる | 「〜円から」ではなく「この作業なら**合計○円**（出張費込み）」 |
| 電話はいつでも押せる位置に | 画面の下に電話ボタンを固定し、どこからでもワンタップで電話できるように |
| 戻れる・やり直せる | フォームは1画面1問。「戻る」ボタンを大きく。入力内容は自動で保存 |
| 家族と共有 | 見積もり・予約内容をLINEやSMSで家族に送れるように |
