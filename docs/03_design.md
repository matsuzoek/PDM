# STEP 3：画面デザイン（v0.3 女性向け配色・ナーチャリング構成）

- デザインのデータ：[`design/lp.html`](../design/lp.html)（スマホ向けの1ページ。ブラウザで開くと見られます）
- 公開プレビュー：https://claude.ai/artifact/UVcvWMFZUqE3rraCt1D1tH （非公開。共有するには、ページの「共有」メニューから設定してください）

## デザインの方針（v0.3）
女性やご高齢の方が「頼みやすい」と感じる、やわらかい配色に変更しました。

| 項目 | ルール |
|---|---|
| メインの色 | ローズ（やさしいピンク）#C24D5C。電話ボタン・数字・見出しの小さなラベル |
| サブの色 | セージ（くすんだ緑）#EEF3EE。スタッフの作業着の緑と合わせている |
| 背景 | 白ではなく、わずかに温かみのある白 #FFFCFA と、淡いピンク #FBF0ED を交互に |
| LINEボタン | ひと目でわかるように、LINEの緑のまま |
| 文字 | 見出しは丸みのある Zen Maru Gothic、本文は読みやすい BIZ UDPゴシック（18px） |
| 形 | ボタンは丸い形、カードは角を少し丸く |
| 写真 | 仮のイメージ写真11枚（`design/img/`）。公開前に実際の写真へ差し替える |

## 画面の順番（ナーチャリング構成）
読む人の気持ちの順番（気づく → 共感する → できると知る → 確かめる → 安心する → 決める）にそって並べ、決めやすい場所ごとに相談ボタンを置いています。

| # | セクション | 読む人の気持ち | 相談ボタン |
|---|---|---|---|
| ① | ヘッダー（受付中かどうかを表示） | | |
| ② | ファーストビュー：写真 →「ひとりで頑張らなくて、大丈夫です。」→ 強み3つ → 電話・LINE | ここなら頼めそう | ● 電話・LINE |
| ③ | こんなこと、ありませんか？（困りごとのチェックリスト5つ） | そうそう、それで困っている | |
| ④ | 何にお困りですか？（写真タイル8つ） | 私の困りごとも頼めるんだ | |
| ⑤ | ご依頼の例（3件。合計料金つき） | 本当にやってもらえるんだ | ● 途中の相談ボタン |
| ⑥ | 安心して頼める3つの理由（女性スタッフ／先に合計金額／家族も安心） | この会社なら安心 | |
| ⑦ | 料金 | いくらかかるか分かった | ● 途中の相談ボタン |
| ⑧ | お客様の声 | ほかの人も満足している | |
| ⑨ | ご利用の流れ（3ステップ） | 頼み方が分かった | |
| ⑩ | よくある質問＋対応エリア | 残っていた不安がなくなった | |
| ⑪ | 最後の相談（受付スタッフの写真つき） | 電話してみよう | ● 電話・LINE |
| 常設 | 画面下の固定バー（上の相談ボタンを過ぎたら表示） | いつでも | ● 電話・LINE |

## 仮で置いているもの（あとで差し替え）
- 電話番号 `0120-000-000`、受付時間「毎日9時〜20時」、LINEは「24時間受け付け」
- 料金（競合の相場をもとにした仮の金額）
- 事例・お客様の声（すべて架空の例）
- 写真（すべて仮のイメージ。画像生成サービスで作成したもの。公開前に実際の写真へ差し替える）
- キャンセル規定（前々日まで無料）
- 支払いは「作業後に現金・カード・PayPay」（ベンチマークは前払いが基本。不安を減らすため後払いにしている）
