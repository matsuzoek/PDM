## デザインの方針
「町の看板」のような**落ち着いた深い緑**を信頼の色にし、目立たせたいところだけ**ひまわり色**を使っています。電話ボタンは緑、LINEボタンはLINEの緑で、ひと目で区別できるようにしています。

| 項目 | ルール |
|---|---|
| 文字 | 本文は**BIZ UDPゴシック**（読みやすさのために作られたユニバーサルデザインの書体）で18px。見出しは丸みのある**Zen Maru Gothic**。16pxより小さい文字は使わない |
| ボタン | 高さ60px、画面いっぱいの幅。アイコンと文字の両方を入れる |
| 色 | 深い緑 #1F5C4F／LINEの緑 #05994A／ひまわり色 #F4B740。ダークモードにも対応 |
| 固定バー | 画面の下に「電話」「LINE」をいつも表示 |
| 料金 | すべて**出張費込みの合計**で表示。事例にも合計金額を載せる |
| イラスト | 色数の少ないシンプルなイラスト（家・スタッフ・電球・タンスなど）。本物の写真ができたら差し替えやすいように、同じ大きさの枠に入れている |

## 画面の順番
① ヘッダー（サイト名・受付時間・東京23区）
② CTA（電話で相談／LINEで相談）
③ キービジュアル（「困ったら、ここを押すだけ。」＋スタッフのイラスト＋安心ポイント3つ）
④ 事例（4件。困りごと・地域と年代・時間・合計料金・お客様の一言）
⑤ 何にお困りですか？（アイコンのタイル8つ）
⑥ 料金のめやす（はじめの1時間5,500円、30分ごとに1,650円、合計の早見表）
⑦ はじめての方も安心です（スタッフを選べる／先に合計金額をお伝え／家族からも頼める）
⑧ ご利用の流れ（3ステップ）
⑨ お客様の声
⑩ よくある質問＋対応エリア（23区の一覧）
⑪ 最後のCTA
⑫ フッター

## 仮で置いているもの（あとで差し替え）
- 電話番号 `0120-000-000`、受付時間「毎日9時〜20時」、LINEは「24時間受け付け」
- 料金（競合の相場をもとにした仮の金額）
- 事例・お客様の声（すべて架空の例）
- キャンセル規定（前々日まで無料）
- 支払いは「作業後に現金・カード・PayPay」（ベンチマークは前払いが基本。不安を減らすため後払いにしている）

4. 受付時間・キャンセル規定・支払い方法
