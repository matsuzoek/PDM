# STEP 3：画面デザイン（v0.2 写真入り）

- デザインのデータ：[`design/lp.html`](../design/lp.html)（スマホ向けの1ページ。ブラウザで開くと見られます）
- 公開プレビュー：https://claude.ai/artifact/UVcvWMFZUqE3rraCt1D1tH （非公開。共有するには、ページの「共有」メニューから設定してください）

## デザインの方針（v0.2）
v0.1の自作イラスト・丸いカード中心のデザインは「AIが作った感」が強かったため、日本の地域サービスのサイトによくある作りに変更しました。

| 項目 | ルール |
|---|---|
| 写真 | 仮のイメージ写真11枚（`design/img/`）。実際の写真ができたら同じファイル名で差し替える |
| 文字 | **BIZ UDPゴシック**1種類。本文18px、16pxより小さい文字は注記だけ |
| 電話 | 電話番号そのものを大きなボタンにし、「通話無料」のラベルをつける |
| 見出し | 左寄せ＋下に黄色の線 |
| 料金 | 赤字の大きな数字。出張費込みの合計と早見表 |
| 色 | 深い緑 #1F5C4F／LINEの緑 #05994A／黄色 #F2C230／料金の赤 #C23A22 |
| 固定バー | 画面の下に「電話する」「LINE」をいつも表示 |

## 画面の順番
① ヘッダー（サイト名・受付時間・東京23区）
② CTA（電話で相談／LINEで相談）
③ キービジュアル（玄関であいさつするスタッフの写真＋「困ったら、ここを押すだけ。」＋数字3つ）
④ 事例（4件。困りごと・地域と年代・時間・合計料金・お客様の一言）
⑤ 何にお困りですか？（アイコンのタイル8つ）
⑥ 料金のめやす（はじめの1時間5,500円、30分ごとに1,650円、合計の早見表）
⑦ うかがうのは、こんなスタッフです（集合写真＋安心ポイント3つ）
⑧ ご利用の流れ（3ステップ）
⑨ お客様の声
⑩ よくある質問＋対応エリア（23区の一覧）
⑪ 最後のCTA
⑫ フッター

## 仮で置いているもの（あとで差し替え）
- 電話番号 `0120-000-000`、受付時間「毎日9時〜20時」、LINEは「24時間受け付け」
- 料金（競合の相場をもとにした仮の金額）
- 事例・お客様の声（すべて架空の例）
- 写真（すべて仮のイメージ。画像生成サービスで作成したもの。公開前に実際の写真へ差し替える）
- キャンセル規定（前々日まで無料）
- 支払いは「作業後に現金・カード・PayPay」（ベンチマークは前払いが基本。不安を減らすため後払いにしている）
