# STEP 2：サイト構成案（v0.2）

> **v0.3（最新）**：「キービジュアル → 相談ボタン」の順にして、共感から相談までを順に読み進める構成（ナーチャリング構成）に変更しました。最新の画面の順番は [03_design.md](./03_design.md) を見てください。

> **v0.2での変更（決定事項を反映）**
> - 形：**A. 自社で受け付けて手配する形**
> - エリア：**東京23区**からスタート
> - スタッフ：**男性・女性を選べる形**
> - 料金（仮）：**はじめの1時間 5,500円（出張費込み）、そのあと30分ごとに1,650円**、車が必要な作業は＋3,300円
> - 受付：**電話とLINEのみ**（Webの申込みフォームはなくした）→ ボタンは「電話」「LINE」の2つ
> - 写真の代わりに**イラスト**を使う
> - サイト名（仮）：**町の便利屋**（ロゴはまだなし）
>
> 以下はv0.1の内容です。上の決定と違うところ（ボタン3つ、3問の申込みフォーム、「女性スタッフ在籍」の表記など）は、決定のほうを優先します。

前提：[01_research.md](./01_research.md) の調査結果をもとに作成。
方針：**スマホ優先・1ページ完結のLP型**。ご指定の「CTA → キービジュアル → 事例集」の順番を最優先にし、ベンチマークのクライアントパートナーズにある要素（安心感・流れ・料金・FAQ）を、よりシンプルにして追加しています。

## 0. コンセプト（案）

> **「困ったら、ここを押すだけ。」**
> ― 電話でも、LINEでも、ボタンひとつで頼める便利屋 ―

差別化の柱は3つです。
1. **合計料金がひと目でわかる**（出張費込みの例を表示。作業後の追加料金なし）
2. **困りごとの言葉で選べる**（「電球」「重い家具」「付き添い」のように、絵＋短い言葉で選ぶ）
3. **家族も安心**（予約内容を家族にLINEで送れる。女性スタッフも指名できる）

## 1. トップページ（LP）の構成

| # | セクション | 目的 | 主な内容 |
|---|---|---|---|
| ① | **ヘッダー** | 誰のサイトかすぐにわかる | ロゴ／「年中無休 8〜21時」／電話番号（タップで電話） |
| ② | **CTA（ファーストビュー最上部）** | 迷わず連絡できる | 大きいボタン3つ：📞電話で相談／💬LINEで相談／📝かんたん申込み（3問だけ） |
| ③ | **キービジュアル** | 安心感・誰が来るかを伝える | スタッフの笑顔の写真＋コピー「困ったら、ここを押すだけ。」＋信頼の数字（例：ご利用○件／女性スタッフ在籍／追加料金なし） |
| ④ | **事例集（ご依頼の例）** | 「こんなことも頼めるんだ」と思ってもらう | カード形式で6件：写真・困りごと・作業時間・**合計料金**・お客様の一言。「もっと見る」で一覧へ |
| ⑤ | **困りごとから選ぶ** | サービスを迷わず探せる | 大きいアイコンのタイル6〜8個（電球・水回り／家具の移動・組立／片付け・ゴミ出し／買い物・付き添い／庭・草むしり／その他なんでも） |
| ⑥ | **料金のめやす** | 料金の不安をなくす | 「1時間 合計○○円（出張費込み）」を大きく表示＋よくある作業の定額表＋「作業後の追加料金はいただきません」 |
| ⑦ | **選ばれる理由（安心ポイント）** | 信頼してもらう | 3つまで：①女性スタッフも指名できる ②事前に合計金額を伝えます ③ご家族へのお知らせもできる |
| ⑧ | **ご利用の流れ** | 依頼のイメージをつかんでもらう | 3ステップ：①連絡する → ②料金を確認 → ③当日おうかがい |
| ⑨ | **お客様の声** | 共感してもらう | 年代・地域・顔のイラストつきで3件 |
| ⑩ | **よくある質問** | 不安を解消する | 5問まで、開閉式（支払い方法／キャンセル／当日頼めるか／女性スタッフ指名／対応エリア） |
| ⑪ | **最後のCTA** | 連絡につなげる | ②と同じボタン3つを、もう一度 |
| ⑫ | **フッター** | 法律面の表示と信頼性 | 会社概要・特定商取引法の表記・プライバシーポリシー・対応エリア |
| 常設 | **下部固定バー** | どこからでも連絡できる | 📞電話／💬LINE の2ボタンを画面下に常に表示 |

## 3. 「かんたん申込み」の流れ（3問＋確認）

1画面に1問、大きいボタンで選んでもらいます。文字入力はできるだけ減らします。

| 画面 | 質問 | 入力方法 |
|---|---|---|
| 1 | 何にお困りですか？ | アイコンのタイルから選ぶ（⑤と同じ） |
| 2 | いつ来てほしいですか？ | 「今日」「明日」「今週中」「日にちを決める」から選ぶ |
| 3 | ご連絡先を教えてください | お名前・電話番号のみ（住所は電話で確認） |
| 確認 | 内容の確認 | 「この内容で送る」＋「家族にも送る（LINE）」 |
| 完了 | 受付完了 | 「○分以内にお電話します」と表示し、電話ボタンも出す |

※料金はお電話で**合計金額**をお伝えし、了承をいただいてから予約を確定します（業界でよくある追加料金トラブルの対策）。

## 4. 下層ページ（最初は最小限）

| ページ | 内容 |
|---|---|
| 事例一覧 | 困りごと別に絞り込み。各事例に写真・時間・合計料金 |
| サービス別ページ（6〜8個） | ⑤の各タイルの行き先。できること・料金例・事例 |
| 料金ページ | 定額表・支払い方法・キャンセル規定 |
| 会社概要・スタッフ紹介 | 顔写真つき（安心感） |
| 法律関係の表示 | 特定商取引法に基づく表記・プライバシーポリシー |

## 5. ベンチマークとの比較

| 項目 | クライアントパートナーズ | 本サイト（案） |
|---|---|---|
| 連絡手段 | 電話・メール | 電話・**LINE**・3問だけの申込み |
| 料金の見せ方 | 1時間3,300円〜＋出張費3,300円〜 | **出張費込みの合計**＋事例ごとの合計料金 |
| サービスの探し方 | サービス名の一覧（とても多い） | **困りごとのアイコン**6〜8個 |
| 利用の流れ | 4ステップ | 3ステップ |
| 安心感 | 女性スタッフ・秘密厳守 | 女性スタッフ指名＋追加料金なし＋家族への共有 |
| 支払い | 原則前払い | 作業後の支払いも選べる（要検討） |
